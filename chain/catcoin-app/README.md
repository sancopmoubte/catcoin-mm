# Catcoin 候选应用源码

本目录是猫猫币（MM）正式网候选的**可追踪应用层源码**。它以父仓库固定的 Cosmos SDK `v0.50.15` 为依赖基线，而不是把任何猫猫币共识修改仅保留在上游 Git 子模块中。候选应用采用 8 位精度：`1 MM = 100,000,000 umm`；链上显示面额为 `mmc`，用户界面符号为 MM。

> 此目录是已编译、已测试的候选实现，不是正式已发行网络。不得将测试 keyring、临时 E2E 私钥、`catcoin-pos-1` 开发网配置或沙盒节点用于正式创世。

## 已实现的 x/claim

`x/claim` 已实现并接入 `catcoind` 的创世、消息路由、查询服务和独立 IAVL 状态。它只从创世时存在的 `claim` 模块账户转出 `umm`，不含 `x/mint` 模块或任何自动铸币路径。

| 规则 | 当前实现 |
|---|---|
| 总量 | 创世候选固定为 `2100000000000000umm`（21,000,000 MM） |
| 启动与领取池 | 三名独立验证者候选各 1 MM；领取池候选为 20,999,997 MM；真实地址尚未填写 |
| 免费领取 | 首笔 1 umm、每 24 小时翻倍、每地址累计 1 MM、末笔截断 |
| 全网日额度 | 每个 UTC 日最多从既有领取池分发 `21000000000umm`（210 MM）；额度用尽即原子拒绝，次日自动重新计数 |
| 防批量地址 | 地址/chain ID/编号/过期时间绑定的 Ed25519 签名凭证；成功后消费编号并持久化 |
| 手续费与收益 | 候选最低 Gas 价格为 `0umm`，无自动 MM 质押收益 |

## 构建与验证

需要匹配项目版本的 Go、`protoc`、`protoc-gen-gogo` 和 `protoc-gen-gocosmos`。协议生成脚本会由仓库的 `.proto` 源码生成 Go 文件，生成文件不应手动编辑。

```bash
cd my-mobile-chain/chain/catcoin-app

# 生成 Protobuf 并构建 catcoind 与仅供本地测试的离线凭证工具
make build

# 执行 x/claim 模块单元测试
make test

# 回到父仓库：启动隔离一验证者候选节点并广播真实 MsgClaim
cd ../..
make claim-e2e
```

`make claim-e2e` 会验证首次领取、当日 210 MM 链上额度、领取池扣减、总供应守恒、未满 24 小时拒绝、跨链凭证拒绝、重复凭证拒绝和重启后的领取记录/凭证持久化。24 小时翻倍、末笔截断、1 MM 地址上限、同日超额拒绝与跨 UTC 日重置均由可控区块时间的状态机单元测试验证。该脚本临时生成 Ed25519 私钥并在结束时删除；正式私钥绝不能进入仓库、创世 JSON、网页或日志。

## 正式发布仍需要什么

正式发布前仍必须完成：唯一正式 chain ID；真实且多方复核的四项创世地址/共识公钥；至少三名独立运营方的持久验证者与哨兵；受保护 RPC、TLS、监控、备份和恢复演练；资格审核、隐私、申诉、签发密钥轮换/撤销制度；独立安全审计；以及发行方对不可逆创世的明确确认。完整要求见父仓库的 [《猫猫币钻石皮书》](../../docs/catcoin-diamond-paper.md)。

自写代码采用 Apache-2.0；依赖的 Cosmos SDK 同样保留 Apache-2.0 许可与上游归属。
